쓰는 방법은 세 가지예요

① GitHub 사이트 (추천)kg4909-design.github.io/samyeok-scanner 주소만 열면 됩니다. 설치가 필요 없고, 휴대폰에서도 열립니다.
시세는 GitHub이 평일마다 자동으로 받아 둡니다. 주문 기록은 내 비공개 저장소에 저장되어 어느 기기에서 열어도 같습니다.
② 내 PC 프로그램설치 파일을 풀고 실행하는 방식입니다. 버튼을 눌러 그 자리에서 시세를 받습니다.
GitHub 연결을 해 두면 PC 프로그램의 주문 기록도 GitHub 사이트와 같아집니다. 맨 아래 "PC 프로그램 설치"를 보세요.

Claude 안에서 여는 화면은 실제 시세를 받을 수 없어 연습용 가상 데이터로만 동작합니다.

GitHub 사이트 처음 설정 (한 번만)

1. 사이트 켜기 (GitHub Pages)

  1. GitHub에서 samyeok-scanner 저장소 → Settings → 왼쪽 Pages.
  2. Build and deployment → Source를 GitHub Actions로 고릅니다.
  3. 저장소 위쪽 Actions 탭 → 왼쪽 시세 업데이트 → 오른쪽 Run workflow → market에 ALL 그대로 두고 Run workflow를 누릅니다.
  4. 노란 점이 초록 체크로 바뀌면(보통 몇 분) https://kg4909-design.github.io/samyeok-scanner/가 열립니다. 이 주소를 즐겨찾기에 넣어 두세요.

그 뒤로는 평일 15:50(국장)과 다음 날 06:40(미장)에 자동으로 시세를 받습니다. GitHub이 바쁠 때는 실행이 늦어질 수 있으니 화면의 "수집" 시각을 확인하세요.

2. 기록 저장소 연결 (기기마다 한 번)

  1. GitHub에 비공개(Private) 저장소 samyeok-records를 만듭니다 ("Add a README file" 체크).
  2. 토큰 만들기 페이지에서:
    • Token name: 아무거나 (예: 삼역호전)
    • Expiration: 원하는 기간. 만료되면 새로 만들어 다시 넣으면 됩니다
    • Repository access: Only select repositories → samyeok-records와 samyeok-scanner
    • Permissions → Repository permissions: Contents: Read and write, Actions: Read and write (Actions는 [지금 시세 다시 받기] 버튼용)
    • Generate token → github_pat_로 시작하는 토큰을 복사해 메모장 등 안전한 곳에 보관
  3. 사이트의 [내 주문 · 보유] 탭 맨 위 "여러 기기 기록 연동" → [연결하기] → 토큰을 붙여 넣고 [연결].
  4. 다른 컴퓨터나 휴대폰에서도 사이트를 열고 같은 토큰으로 연결하면 끝입니다.
토큰은 비밀번호와 같습니다. 다른 사람에게 보여 주거나 PC방 같은 공용 컴퓨터에 넣지 마세요. 잃어버리거나 노출됐으면 GitHub 설정 → Developer settings → Personal access tokens에서 지우고 새로 만드세요.

매일 쓰는 법

  1. 사이트를 엽니다. 맨 위 "시세 · GitHub 자동 수집"에 오늘 수집 시각이 보이면 최신 시세입니다. PC 프로그램이라면 [국장 시세 받기]를 누릅니다.
  2. 오늘 살 종목 탭에서 초록색 "매수 후보" 종목을 누릅니다.
  3. 오른쪽 주문표의 살 수량 · 손절가 · 1차 익절가 · 2차 익절가를 증권사 앱의 감시주문(스탑로스/OCO)에 그대로 넣습니다. [복사] 버튼으로 메모를 복사해 두면 편합니다.
  4. 예약 주문을 걸었다면 [이 주문 계획 저장]을 눌러 둡니다 (아래 "예약 주문을 걸었다면" 참고).
시장최신 시세가 들어오는 시각 (한국시간)
국장GitHub 자동 수집 평일 15:50 · PC 프로그램은 15:40 이후 직접
미장GitHub 자동 수집 다음 날 06:40 · PC 프로그램은 06:10 이후 직접 (미국 서머타임 기간 05:10 이후)

장중에 받으면 아직 끝나지 않은 오늘 봉은 자동으로 빠지고 어제까지로 판정합니다.

화면 읽는 법

표시뜻할 일
매수 후보조건을 모두 충족했고 내 시드로 살 수 있음주문표대로 주문
시드 부족조건은 맞지만 1주 가격이 너무 비싸거나, 1주만 사도 허용 손실을 넘음건너뜀
관찰조건이 1개 모자람사지 않음. 내일 다시 확인
대기조건이 2개 이상 모자람사지 않음
손절가 (파란색)이 가격 아래로 내려가면 전량 판다감시주문으로 미리 걸어 둠
1차 익절가 (빨간색)여기 오면 절반 팔고, 남은 절반의 손절가를 산 가격으로 올림감시주문으로 미리 걸어 둠

"내 계좌" 칸에 시드를 넣으면 살 수량과 예상 손익이 모두 그 금액에 맞춰 다시 계산됩니다. 실제로 산 가격이 오늘 종가와 다르면 주문표 아래 칸에 입력하세요.

전략 검증 탭은 기본 세 전략과 지금 쓰는 전략을 자세히 비교하고, 전략 연구소 탭은 120개 전략을 한꺼번에 비교합니다.

예약 주문을 걸었다면: 저장 → 다음 날 체결 확인 → 보유 관리

  1. 전날: 매수 후보 종목의 주문표에서 [이 주문 계획 저장]을 누릅니다. 여러 종목이면 목록 위 [매수 후보 전부 저장].
  2. 다음 날 (장 마감 후 시세가 들어온 뒤): [내 주문 · 보유] 탭의 "① 체결 확인 대기"에서 실제로 사진 종목은 [체결됨], 안 사진 종목은 [안 사짐].
    • 시장가로 샀다면 산 가격 칸에 그날 시가가 자동으로 들어갑니다. 증권사 체결 내역과 다르면 고쳐 주세요.
    • 산 가격이 바뀌면 손절가는 그대로 두고 1차·2차 익절가를 그 가격 기준으로 다시 계산합니다.
  3. 보유하는 동안: "② 보유 중"에 지금 걸어 둘 손절·익절 주문이 항상 보이고, 새 시세가 들어올 때마다 손절가·익절가에 닿았는지 점검해 알려줍니다.
    • 1차 익절이 체결되면 [1차 익절 체결 기록] → 남은 수량의 손절가가 산 가격(본절)으로 바뀝니다.
    • 손절이나 나머지 매도가 체결되면 [매도 기록] → 다 팔면 "③ 매매 일지"로 옮겨집니다.
  4. 저장을 깜빡하고 이미 샀다면 "② 보유 중"의 [직접 추가]로 종목코드, 산 가격, 수량, 손절가를 넣으세요.

전략 연구소: 어떤 매매법이 잘 맞았는지 비교하고 골라 쓰기

  1. [전략 연구소] 탭에서 국장/미장을 고르고 [120개 전략 시뮬레이션]을 누릅니다. MACD, 이동평균 골든크로스, RSI, 볼린저밴드, 신고가 돌파, 스토캐스틱, 급락 후 반등, 거래량 급증, 삼역호전 등 24가지 매수 신호 × 5가지 청산 방식을 내 시드와 같은 조건으로 돌립니다.
  2. 결과는 기간 앞 70%로 순위를 매기고, 뒤 30%(전략이 본 적 없는 기간) 성적을 함께 보여줍니다. 통과는 앞·뒤 모두 계좌 수익이 난 전략입니다.
  3. 맨 위 카드의 "단순 보유"는 같은 종목을 그냥 사서 들고 있었을 때입니다. 매매 전략이 이걸 못 이기면 굳이 매매할 이유가 약합니다.
  4. 마음에 드는 전략 줄의 [국장에 쓰기](또는 미장)를 누르면 오늘 살 종목·주문표·내 주문 관리가 모두 그 전략 기준으로 바뀝니다. 되돌리려면 "전략 · 데이터 · 세부 설정"의 시장별 전략에서 고르세요.
120개를 같은 데이터로 돌리면 일부는 운으로 좋게 나옵니다. 뒤 기간 성적이 제일 좋은 전략을 고르면 같은 함정에 다시 빠지니, "추천"(양쪽 기간 모두 수익인 전략 중 앞 기간 1위)을 기준으로 삼고 소액으로 실전 기록을 쌓아 확인하세요.

여러 기기에서 같은 기록 쓰기

  • 위 "기록 저장소 연결"을 각 기기에서 한 번씩 하면, 집에서 저장하거나 체결 처리한 종목이 회사 PC나 휴대폰에도 그대로 보입니다. 반대도 마찬가지입니다.
  • 계좌 시드, 전략 선택, 세부 설정도 함께 맞춰집니다.
  • 화면을 켜 둔 동안 30초마다 다른 기기의 변경을 확인합니다. 반영되면 화면 아래에 알림이 뜹니다.
  • 같은 종목을 두 기기에서 동시에 고치면 나중에 고친 쪽이 남습니다. 같은 날 같은 종목을 두 기기에서 각각 저장했다면 하나로 자동 정리됩니다.
  • 기록은 samyeok-records 저장소의 trades.json, settings.json에 저장되고, GitHub에 변경 이력이 모두 남아 실수로 지워도 되돌릴 수 있습니다.

업데이트 받는 법

  • GitHub 사이트: Claude가 저장소에 새 버전을 올리면 몇 분 안에 사이트가 자동으로 바뀝니다. 할 일이 없습니다. 바로 안 바뀌면 새로고침하세요.
  • PC 프로그램: Claude가 주는 새 index.html을 스캐너 화면 위로 끌어다 놓거나 맨 위 [업데이트 파일 적용]으로 고릅니다. server.py까지 바뀌는 큰 업데이트는 새 zip을 같은 자리에 풀어 덮어쓴 뒤 바로가기를 다시 실행합니다.

PC 프로그램 설치 (선택)

  1. Claude가 보내 준 samyeok-scanner.zip을 내려받아 마우스 오른쪽 클릭 → "압축 풀기" 합니다.
    압축 파일을 더블클릭해 안을 들여다본 상태에서 바로 실행하면 안 됩니다. 꼭 압축을 푼 다음 실행하세요.
  2. 풀린 폴더의 START_scanner.bat를 더블클릭합니다.
    • 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
    • 파이썬이 없으면 열리는 python.org에서 설치합니다. 설치 첫 화면 아래 "Add python.exe to PATH"를 꼭 체크한 뒤 다시 더블클릭합니다.
    • 처음에는 필요한 부품을 자동으로 설치합니다 (1~3분).
  3. 브라우저에 스캐너가 열리고 바탕화면에 "Samyeok Scanner" 바로가기가 생깁니다. 다 쓰면 검은 창을 닫습니다.
  4. 맥은 START_mac.command를 마우스 오른쪽 클릭 → 열기 (파이썬은 python.org에서 먼저 설치).
samyeok-scanner\
├─ START_scanner.bat   ← 이것만 더블클릭 (처음 1번, 이후엔 바탕화면 바로가기)
├─ GUIDE.html          ← 사용설명서 = 지금 이 내용
├─ START_mac.command   ← 맥에서만 사용
├─ app\                ← 프로그램 본체 (건드리지 않아도 됨)
└─ data\               ← 받은 시세(KR.json, US.json)와 주문 기록(trades.json)

문제가 생기면

증상해결
사이트 주소가 404Settings → Pages의 Source가 GitHub Actions인지 확인하고, Actions 탭에서 시세 업데이트 → Run workflow를 한 번 실행하세요.
수집 시각이 오래됨 / "수집 실패"Actions 탭에서 빨간 X가 있는 실행을 눌러 내용을 캡처해 Claude에게 보여 주세요. 지난 시세는 그대로 쓰입니다.
"토큰이 맞지 않거나 만료되었습니다"토큰이 만료됐거나 잘못 복사됐습니다. 새로 만들어 다시 연결하세요.
"저장소를 찾을 수 없습니다"토큰을 만들 때 Repository access에 samyeok-records를 선택했는지 확인하세요.
"이 저장소는 공개(Public)입니다"기록 저장소는 반드시 비공개여야 합니다. 저장소 Settings 맨 아래에서 Private으로 바꾸세요.
(PC) 더블클릭하면 창이 번쩍하고 사라짐압축을 풀지 않고 실행했을 가능성이 큽니다. 압축을 푼 폴더에서 다시 실행하세요.
(PC) 브라우저가 안 열림검은 창에 나온 주소(예: http://127.0.0.1:8765/)를 주소창에 직접 입력하세요.
어떤 문제든 화면이나 오류 내용을 캡처해서 Claude에게 보여 주면 바로 고쳐 드립니다.
