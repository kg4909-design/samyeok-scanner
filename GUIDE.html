설치부터 매일 쓰는 법, 업데이트, 문제 해결까지

쓰는 방법은 세 가지예요

① GitHub 사이트 (추천)kg4909-design.github.io/samyeok-scanner 주소만 열면 됩니다. 설치가 필요 없고, 휴대폰에서도 열립니다.
시세는 GitHub이 평일마다 자동으로 받아 둡니다. 주문 기록은 내 비공개 저장소에 저장되어 어느 기기에서 열어도 같습니다.
② 내 PC 프로그램설치 파일을 풀고 실행하는 방식입니다. 버튼을 눌러 그 자리에서 시세를 받습니다.
GitHub 연결을 해 두면 PC 프로그램의 주문 기록도 GitHub 사이트와 같아집니다. 맨 아래 "PC 프로그램 설치"를 보세요.

Claude 안에서 여는 화면은 실제 시세를 받을 수 없어 연습용 가상 데이터로만 동작합니다.

GitHub 사이트 처음 설정 (한 번만)

1. 사이트 켜기 (GitHub Pages)

  1. GitHub에서 samyeok-scanner 저장소 → Settings → 왼쪽 Pages.
  2. Build and deployment → Source를 GitHub Actions로 고릅니다.
  3. 저장소 위쪽 Actions 탭 → 왼쪽 시세 업데이트 → 오른쪽 Run workflow → market에 ALL 그대로 두고 Run workflow를 누릅니다.
  4. 노란 점이 초록 체크로 바뀌면(보통 몇 분) https://kg4909-design.github.io/samyeok-scanner/가 열립니다. 이 주소를 즐겨찾기에 넣어 두세요.

그 뒤로는 평일 15:50(국장)과 다음 날 06:40(미장)에 자동으로 시세를 받습니다. GitHub이 바쁠 때는 실행이 늦어질 수 있으니 화면의 "수집" 시각을 확인하세요.

2. 기록 저장소 연결 (기기마다 한 번)

  1. GitHub에 비공개(Private) 저장소 samyeok-records를 만듭니다 ("Add a README file" 체크).
  2. 토큰 만들기 페이지에서:
    • Token name: 아무거나 (예: 삼역호전)
    • Expiration: 원하는 기간. 만료되면 새로 만들어 다시 넣으면 됩니다
    • Repository access: Only select repositories → samyeok-records와 samyeok-scanner
    • Permissions → Repository permissions: Contents: Read and write, Actions: Read and write (Actions는 [지금 시세 다시 받기] 버튼용)
    • Generate token → github_pat_로 시작하는 토큰을 복사해 메모장 등 안전한 곳에 보관
  3. 사이트의 [매매일지] 탭 맨 위 "여러 기기 기록 연동" → [연결하기] → 토큰을 붙여 넣고 [연결].
  4. 다른 컴퓨터나 휴대폰에서도 사이트를 열고 같은 토큰으로 연결하면 끝입니다.
토큰은 비밀번호와 같습니다. 다른 사람에게 보여 주거나 PC방 같은 공용 컴퓨터에 넣지 마세요. 잃어버리거나 노출됐으면 GitHub 설정 → Developer settings → Personal access tokens에서 지우고 새로 만드세요.

매일 쓰는 법

  1. 사이트를 엽니다. 맨 위 "시세 · GitHub 자동 수집"에 오늘 수집 시각이 보이면 최신 시세입니다. PC 프로그램이라면 [국장 시세 받기]를 누릅니다.
  2. 오늘 살 종목 탭에서 초록색 "매수 후보" 종목을 누릅니다.
  3. 오른쪽 주문표의 살 수량 · 손절가 · 1차 익절가 · 2차 익절가를 증권사 앱의 감시주문(스탑로스/OCO)에 그대로 넣습니다. [복사] 버튼으로 메모를 복사해 두면 편합니다.
  4. 예약 주문을 걸었다면 [예약 주문 저장], 이미 샀다면 [매수 기록]을 누릅니다 (아래 "매매일지" 참고).
시장최신 시세가 들어오는 시각 (한국시간)
국장GitHub 자동 수집 평일 15:50 · PC 프로그램은 15:40 이후 직접
미장GitHub 자동 수집 다음 날 06:40 · PC 프로그램은 06:10 이후 직접 (미국 서머타임 기간 05:10 이후)

장중에 받으면 아직 끝나지 않은 오늘 봉은 자동으로 빠지고 어제까지로 판정합니다.

화면 읽는 법

표시뜻할 일
매수 후보조건을 모두 충족했고 내 시드로 살 수 있음주문표대로 주문
시드 부족조건은 맞지만 1주 가격이 너무 비싸거나, 1주만 사도 허용 손실을 넘음건너뜀
관찰조건이 1개 모자람사지 않음. 내일 다시 확인
대기조건이 2개 이상 모자람사지 않음
손절가 (파란색)이 가격 아래로 내려가면 전량 판다감시주문으로 미리 걸어 둠
1차 익절가 (빨간색)여기 오면 절반 팔고, 남은 절반의 손절가를 산 가격으로 올림감시주문으로 미리 걸어 둠

"내 계좌" 칸에 운용 자산(시드)을 넣으면 살 수량과 예상 손익이 모두 그 금액에 맞춰 다시 계산됩니다. 실제로 산 가격이 오늘 종가와 다르면 주문표 아래 칸에 입력하세요.

전략 검증 탭은 기본 세 전략과 지금 쓰는 전략을 자세히 비교하고, 전략 연구소 탭은 120개 전략을 한꺼번에 비교합니다.

매매일지: 기록 → 매일 점검 → 원칙 체크 → 복기

  1. 샀을 때: [오늘 살 종목]에서 종목을 누르고 주문표의 [매수 기록]. 종목·날짜·진입가·손절가·1R·수량이 채워져 있으니 실제 체결가와 수량만 고치고 [보유 종목으로 기록]. 체결가를 바꾸면 손절가·1R·익절가가 그 가격 기준으로 다시 계산됩니다.
    • 예약만 걸어 둔 경우는 [예약 주문 저장] → 다음 날 [매매일지] "① 체결 확인 대기"에서 [체결됨]/[안 사짐].
    • 신호대로 산 게 아니면(추격 매수, 수량 초과 등) "원칙대로 샀다" 체크를 끄세요.
  2. 보유하는 동안: "② 보유 중"이 새 시세가 들어올 때마다 그 종목을 산 전략의 규칙으로 점검합니다. 미너비니는 손절 −10%, +15% 뒤 본전 손절, 종가 50일선 이탈. 5일선 눌림목은 손절 −4%, +5% 뒤 본전 손절, 종가 20일선 이탈, 15거래일.
  3. 팔았을 때: [매도 기록] → 판 날·가격·수량·사유를 적고 "원칙대로 팔았다"를 체크합니다. 알림이 떠서 판 경우만 체크하고, 겁이 나서 일찍 팔았거나 손절가를 무시하고 버틴 경우는 체크하지 않습니다.
  4. 성과 보기: "③ 성과"에 승률, 거래당 평균 R, 누적 손익, 최대 낙폭, 계좌 곡선이 나오고, 원칙 지킨 매매와 어긴 매매를 나눠 비교합니다.
  5. 한 달에 한 번: "④ 월간 복기"에서 그달 판 종목과 원칙 준수율을 보고 메모를 남깁니다.
  6. 30건 규칙: 판 종목이 30건이 될 때까지 맨 위에 "기법 변경 금지"가 뜨고, 설정에서 전략을 바꾸려 하면 한 번 더 확인합니다. 표본이 적으면 좋은 규칙도 연속 손절이 나오기 때문입니다.

되돌려보기: 그날 신호를 샀다면 지금은?

  1. [되돌려보기] 탭에서 시장·전략을 고르고, 신호 날짜를 달력이나 1·5·10·20·60일 전 버튼으로 정합니다. 휴장일을 고르면 그 전 거래일로 바뀝니다.
  2. 그날 하루 신호: 그날 장 마감 기준으로 검색된 종목을 다음 거래일에 전략 방식(미너비니 = 시가, 5일선 눌림목 = 그날 5일선 지정가)으로 샀다고 보고, 오늘까지 전략 규칙대로 손절·익절·청산을 따라갑니다. 지정가가 안 닿았으면 미체결로 표시합니다.
  3. 그날부터 오늘까지 매일 신호: 그 기간 매일 나온 신호를 모두 따라갑니다(같은 종목은 판 뒤의 다음 신호부터). 계좌 기준 누적 손익 그래프가 함께 나옵니다.
  4. 결과: 종목마다 보유 중이면 현재가와 수익률, 팔렸으면 판 날·판 가격·사유(손절·본전 손절·분할 익절·종가 청산)와 수익률·R. 위에는 승률, 같은 금액씩 샀을 때의 평균 수익률, 내 운용 자산·1회 손실 규칙·동시 보유 한도로 샀을 때의 손익과 누적 수익률이 나옵니다. 행을 누르면 매수·매도 과정이 날짜별로 펼쳐집니다.
  5. 일봉만으로 계산하므로, 하루 안에서 손절가와 익절가가 둘 다 닿은 날은 손절이 먼저라고 보고, 지정가로 산 날의 익절은 다음 날부터 인정합니다(실제보다 조금 보수적).

순자산 · 현금흐름

  1. [순자산] 탭 → [기본 계좌 만들기] 또는 [계좌 추가]. 이름과 종류만 적습니다(계좌번호는 적지 않습니다).
  2. 매달 말일(또는 월급날) "월 기록 입력"에 계좌별 잔액, 그달 수입·지출을 적고 저장합니다. 지난달 값과 같으면 [같게]를 누르면 됩니다. 부채는 남은 금액을 양수로 적습니다.
  3. 순자산 그래프, 수입·지출 막대, 저축률(=(수입−지출)÷수입), 목표 금액 달성 예상일(순자산 추세 기준 / 저축액만 기준)이 계산됩니다.
  4. 종류가 투자 · 국장 주식 / 투자 · 미장 주식인 계좌의 최근 달 잔액은 위 "내 계좌"의 국장·미장 운용 자산에 자동으로 들어가 매수 수량 계산에 쓰입니다(계좌 관리의 체크로 끌 수 있음). 미장 계좌는 원화로 환산해 적습니다.

백업

  • [순자산] 탭 맨 아래 [백업 파일 내보내기] → 매매 기록·순자산·복기 메모·설정이 samyeok-backup-날짜.json 파일 하나로 다운로드 폴더에 저장됩니다. 구글 드라이브 등에 옮겨 두세요. GitHub 토큰은 들어가지 않습니다.
  • 마지막 백업 후 7일이 지나면 화면 위에 주간 백업 알림이 뜹니다.
  • [백업 파일 불러오기]는 지금 기록과 합칩니다(같은 기록은 더 최근에 고친 쪽을 남김). 휴대폰을 바꿨을 때도 이걸로 옮기면 됩니다.

갤럭시(안드로이드) 홈 화면에 앱처럼 추가

  1. 휴대폰 Chrome에서 사이트를 엽니다.
  2. 오른쪽 위 ⋮ → 홈 화면에 추가(버전에 따라 앱 설치) → [추가]. 삼성 인터넷이라면 아래 ≡ → 현재 페이지 추가 → 홈 화면.
  3. 홈 화면의 "스캐너" 아이콘으로 열면 주소창 없이 앱처럼 열립니다. 마지막으로 보던 탭(매매일지·순자산)에서 시작합니다.
  4. 휴대폰에서도 "여러 기기 기록 연동"에 같은 토큰을 한 번 넣으면 PC와 같은 기록이 보입니다. 인터넷이 끊겨도 마지막으로 받은 화면은 열립니다.

매매 전략: 국장 미너비니 SEPA · 미장 5일선 눌림목

[설정 → 전략 · 데이터 · 세부 설정]에서 시장별로 둘 중 하나를 고릅니다. 기본값은 이 앱 백테스트에서 그 시장에 더 나았던 쪽입니다.

미너비니 SEPA (국장 기본)

  • 마크 미너비니(미국 투자 챔피언십 우승)의 공개 규칙: 이평선 정배열 + 52주 고가 근처 + 상대강도 70 이상 + 좁은 횡보 후 거래량 실린 피벗 돌파.
  • 살 때: 신호가 나온 날 저녁 다음 날 시가 예약 매수. 손절 −10%, +15% 오르면 손절가를 산 가격으로 올림, 익절 목표가는 없음, 종가가 50일선 아래로 마감하면 다음 날 시가 매도.
  • 조건이 까다로워 신호가 드뭅니다(최근 국장 기준 한 달에 1~2번 수준). 살 종목이 없는 날이 대부분이며, 그날은 규칙상 쉬는 날입니다.

5일선 눌림목 (미장 기본)

  • 거래대금이 크게 터진 첫 장대양봉(하루 +7% 이상, 거래대금 미장 5억 달러·국장 500억 원 이상, 거래량 1.5배, 60일 신고가) 뒤, 아직 5일선까지 안 내려온 종목.
  • 살 때: 저녁에 다음 날 오늘 5일선 가격 지정가 매수를 예약합니다. 안 사지면 다음 날 저녁 새 5일선 가격으로 다시 겁니다(장대양봉 뒤 6거래일까지).
  • 사지면: 손절 감시주문 −4%, +5% 오르면 손절가를 산 가격으로 올림, 익절 목표가는 없음. 종가가 20일선 아래로 마감하면 다음 날 시가 매도. 최대 15거래일 보유.
  • 국장 백테스트에서는 손실이었습니다. 국장에서 쓰려면 [고수 전략 검증] 결과를 먼저 확인하세요.

손절·익절 비율은 어떻게 정했나 (2026-11 백테스트)

  • 신호는 그대로 두고 손절 폭, 익절 목표, 본전 손절 시점, 추세 청산선, 최대 보유일만 바꿔 국장 미너비니 2,240가지, 미장 눌림목 2,688가지를 최근 4년 일봉으로 돌렸습니다. 같은 날 신호를 사는 순서를 200번 무작위로 바꾼 결과의 중앙값으로 비교했습니다.
  • 국장 미너비니: 손절 −7% → −10%. 연 +11.6% → +21.0%, 최대 낙폭 15.7% → 6.5% (시드 100만 원·3종목·1회 손실 1%). −7%는 정상적인 흔들림에 자주 걸려 손절된 뒤 다시 오르는 경우가 많았습니다. 익절 목표가(+10~50%)를 두면 모든 경우 수익이 크게 줄어 두지 않습니다.
  • 미장 눌림목: 손절 −5% → −4%, +5%에서 본전 손절, +3·6·9% 분할 익절 폐지, 청산선 10일선 → 20일선. 연 +10.8% → +22.0%, 최대 낙폭 3.8% → 6.4%. 작은 분할 익절이 크게 오르는 종목의 수익을 잘라 먹었습니다.
  • 손절 폭이 넓어도 잃는 돈은 같습니다. 수량은 "손절 시 운용 자산의 1%만 잃도록" 계산하므로, 손절이 −10%면 수량이 줄고 −4%면 늘어납니다. 손절 폭은 "얼마나 흔들림을 버틸지"만 정합니다.
  • 과거에 가장 좋았던 값을 고른 것이라 앞으로도 같다는 보장은 없습니다. 다만 앞 70%·뒤 30% 기간, 시드 10배, 5종목, 1회 손실 0.5% 조건에서도 모두 새 값이 더 나았습니다.

메트릭 스튜디오 지표 검증 (2026-11)

  • 문병로 교수의 『메트릭 스튜디오』(2014)에서 유의미하다고 한 기술적 지표(지수 이동평균 추세, 정배열, 볼린저밴드 돌파, 52주 신고가, 이격도, 6개월 모멘텀 등)를 이 앱의 최근 4년 일봉으로 다시 확인했습니다. PER·PBR 같은 기본적 지표는 재무 자료가 없어 확인하지 못했습니다.
  • 반영한 것: 국장 미너비니에 "시장(국장 300종목 동일가중 지수)이 200일선 위일 때만 매수" 조건을 더했습니다. 연 +19.9% → +20.2%로 수익은 비슷하고, 최대 낙폭은 7.8% → 4.1%로 줄었습니다. 시드 10배·5종목·1회 손실 0.5% 조건에서도 모두 수익이 같거나 높고 낙폭은 작았습니다. 책의 "개별 종목보다 지수의 이동평균 추세가 유의미하다"는 결론과 같은 방향입니다.
  • 반영하지 않은 것: 미장에는 같은 시장 조건이 효과가 없었습니다. 6개월 모멘텀·이격도 반등은 따로 보면 평균보다 나았지만, 전략으로 만들면 지금 전략보다 수익이 낮았습니다. 변동성이 작을 때의 볼린저밴드 상단 돌파는 책과 달리 이 기간에는 오히려 평균보다 나빴습니다.

어떤 종목을 보나요

  • 국장: 코스피·코스닥 시가총액 상위 300개 보통주. 우선주(삼성전자우, 현대차2우B 등)는 거래하지 않으므로 뺍니다. 순위는 시세를 받을 때마다 새로 정합니다.
  • 미장: 지금 S&P 500에 들어 있는 종목 전체. 한 회사가 주식을 두 종류 상장한 경우(구글 GOOGL·GOOG 등)는 거래대금이 큰 쪽 하나만 봅니다.

전거래일 · 최근 5거래일 신호

  • [오늘 살 종목] 목록 위 [전거래일], [최근 5거래일]을 누르면 그 기간에 나온 신호도 찾아 줍니다. 하루 이틀 확인을 못 한 날에 유용합니다.
  • 미너비니는 이미 많이 오른 종목을 사지 않도록, 오늘 종가가 피벗 대비 +5% 이내이고 50일선 위일 때만 매수 후보로 표시합니다. 5%를 넘으면 추격 금지, 피벗 아래로 되밀리면 보류입니다.
  • 미너비니 과거 신호의 주문표는 내일 시가 매수 기준이고, 매수가는 오늘 종가로 추정합니다. 5일선 눌림목은 그 뒤 이미 5일선에 닿았으면 보류, 아직이면 오늘 5일선 가격으로 다시 지정가를 계산합니다.

고수 전략 검증 탭

지금 쓰는 전략이 여전히 맞는 선택인지 미너비니·5일선 눌림목·터틀·홀리 그레일과 예전 전략을 같은 조건으로 비교해 보는 곳입니다. 한 달에 한 번쯤 시장별로 [검증 실행]을 눌러, 쓰는 전략이 계속 "통과"인지 확인하세요. 미너비니와 5일선 눌림목 카드에는 [매일 쓰는 전략으로] 버튼이 있습니다. 몇 달 연속 다른 전략이 추천으로 나오면 그때 전략을 다시 생각하면 됩니다.

여러 기기에서 같은 기록 쓰기

  • 위 "기록 저장소 연결"을 각 기기에서 한 번씩 하면, 집에서 저장하거나 체결 처리한 종목이 회사 PC나 휴대폰에도 그대로 보입니다. 반대도 마찬가지입니다.

PC 프로그램 설치 (선택)

  1. Claude가 보내 준 samyeok-scanner.zip을 내려받아 마우스 오른쪽 클릭 → "압축 풀기" 합니다.
    압축 파일을 더블클릭해 안을 들여다본 상태에서 바로 실행하면 안 됩니다. 꼭 압축을 푼 다음 실행하세요.
  2. 풀린 폴더의 START_scanner.bat를 더블클릭합니다.
    • 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
    • 파이썬이 없으면 열리는 python.org에서 설치합니다. 설치 첫 화면 아래 "Add python.exe to PATH"를 꼭 체크한 뒤 다시 더블클릭합니다.
    • 처음에는 필요한 부품을 자동으로 설치합니다 (1~3분).
  3. 브라우저에 스캐너가 열리고 바탕화면에 "Samyeok Scanner" 바로가기가 생깁니다. 다 쓰면 검은 창을 닫습니다.
  4. 맥은 START_mac.command를 마우스 오른쪽 클릭 → 열기 (파이썬은 python.org에서 먼저 설치).
samyeok-scanner\
